# venixOS landing page concept

A standalone landing-page prototype for venixOS.

## Included
- `index.html` — responsive single-page site with all CSS and JS embedded.
- `assets/pukno-logo.jpeg` — PUKNO logo used in the concept UI.
- Temporary COSMIC screenshots are referenced from the official System76 CDN so they can be replaced later with venixOS screenshots.

## Temporary brand-color switcher
The fixed header contains a dropdown that changes the main brand color live between:
- `#4a0e17` (default)
- `#1e102f`
- `#4a154b`
- `#5c0632`
- `#660033`

The selected option is stored in browser `localStorage`.

## Notes
This is a concept/product-direction page. COSMIC / Pop!_OS imagery is temporary reference material from System76 and should be replaced with original venixOS product screenshots before a production launch.
